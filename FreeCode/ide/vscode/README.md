# FreeCode Bridge — إضافة VS Code

إضافة رقيقة (لا ذكاء محلي فيها): ترسل مهمتك مع سياق المحرر إلى جسر FreeCode في تطبيق سطح المكتب، وتعرض ردّ الوكيل والأدوات لحظياً.

## التثبيت

1. في تطبيق FreeCode: `/bridge on` (أو الإعدادات → جسر IDE). هذا يولّد رمزاً ويشغّل الجسر على `127.0.0.1:4177`.
2. انسخ الرمز من `/bridge`.
3. في VS Code:
   ```bash
   cd ide/vscode
   npx @vscode/vsce package      # أو: zip -r freecode-bridge.zip .
   code --install-extension freecode-bridge-0.1.0.vsix
   ```
   أو للتجربة السريعة: انسخ المجلد إلى `~/.vscode/extensions/freecode-bridge-0.1.0/` وأعد تشغيل VS Code.
4. من الإعدادات: `freecode.bridgeUrl` و`freecode.bridgeToken` (والاختيارية `freecode.allowCommands` للسماح بأوامر shell العادية — الأوامر الخطرة تُرفض دائماً).

## الاستخدام

| الأمر | ما يفعله |
|---|---|
| `FreeCode: اسأل عن المشروع` | يرسل سؤالك مع مسار الملف المفتوح وسطر المؤشر |
| `FreeCode: اسأل عن التحديد الحالي` | يرفق النص المحدد كاملاً في السياق |
| `FreeCode: حالة الجسر` | يعرض المشروع والمنفذ وآخر نتيجة |

الرد يظهر في لوحة **Output → FreeCode** ويتحدّث لحظياً (نفس بثّ التطبيق: نص، أدوات، ملاحظات، أخطاء).

## ملاحظات

- الجسر يستمع على `127.0.0.1` فقط ويطلب رمزاً في كل طلب؛ لا يُتاح على الشبكة المحلية.
- عند غياب الرمز أو توقف التطبيق تعرض الإضافة رسالة واضحة مع زر لفتح الإعدادات.
- الأوامر: إن لم تفعّل `allowCommands`، تُنفَّذ أدوات الملفات فقط وتُرفض أوامر shell.
